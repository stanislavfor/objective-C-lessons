### Решение задания

<br><br>

#### Работа мобильного приложения

Данное мобильное приложение позволяет отправлять GET и POST-запросы и <br>
получать результаты в таблице на втором и третьем экранах. <br>
В текстовое поле на первом экране ввести параметры GET-запроса и параметры <br>
POST-запроса в соответствующих полях.
Нажать кнопку "GET" для отправки GET-запрос на сервер сервиса https://postman-echo.com/get или <br>
нажать кнопку "POST" для отправки POST-запрос на сервер сервиса https://postman-echo.com/post. <br>
Нажать кнопку "FORWARD" и перейти на второй экран или при POST-запросе сразу перейти на третий экран. <br>
На втором и третьем экранах отображаются данные, полученные с сервера, в таблице. <br>
Можно нажать кнопку "RESET" для очистки данных <br>
или кнопку "BACK TO" для возврата на первый экран (начальное окно). <br>

#### Содержание проекта

**FirstViewController** содержит методы: <br>
1. viewDidLoad - настраивает интерфейс (setupUI) при загрузке первого экрана.
2. setupUI - создает и настраивает текстовое поле (queryTextField), кнопку "GET" (getButton), кнопку "FORWARD" (forwardButton). <br>  
3. getButtonTapped: Вызывается при нажатии на кнопку "GET". Отправляет GET-запрос с параметрами из текстового поля с помощью класса Loader. <br>
4. forwardButtonTapped: Вызывается при нажатии на кнопку "FORWARD". Переходит на второй экран (SecondViewController) и передает данные, полученные с сервера. <br>
5. postButtonTapped - при нажатии на кнопку "POST" отправляет POST-запрос на сервер с параметрами из текстового поля postQueryTextField <br>
   и переводит на третью страницу (ThirdViewController) и передает данные, полученные с сервера. <br>

**SecondViewController** содержит методы: <br>
1. viewDidLoad - настраивает интерфейс (setupUI) при загрузке второго экрана. <br>
2. setupUI - создает и настраивает кнопку "RESET" (resetButton), кнопку "BACK TO" (backButton), таблицу (tableView). Устанавливает ограничения для элементов интерфейса. <br>
3. resetTapped - при нажатии на кнопку "RESET", очищает данные в таблице. <br>
4. backTapped - при нажатии на кнопку "BACK TO", возвращает на первый экран. <br>
5. tableView numberOfRowsInSection - возвращает количество строк в таблице, равное количеству элементов в массиве data. <br>
6. tableView cellForRowAtIndexPath - настраивает ячейки таблицы. <br>

**ThirdViewController** содержит методы: <br>
1. viewDidLoad - настраивает интерфейс (setupUI) при загрузке третьего экрана.
2. setupUI - создает и настраивает кнопки "RESET", "BACK TO", таблицу (tableView). <br>
3. resetTapped - при нажатии на кнопку "RESET", очищает данные в таблице. <br>
4. backTapped - при нажатии на кнопку "BACK TO", возвращает на первый экран. <br>
5. tableView numberOfRowsInSection - возвращает количество строк в таблице, равное количеству элементов в массиве data. <br>
6. tableView cellForRowAtIndexPath - настраивает ячейки таблицы. <br>
    **Loader** - отправляет GET-запрос на сервер с параметрами из строки запроса (fetchDataWithQuery completion) и <br>
отправляет POST-запрос на сервер с параметрами из строки запроса. <br>
    **AppDelegate и SceneDelegate** - настраивают начальное окно приложения и <br>
устанавливают FirstViewController в качестве корневого контроллера. <br>
