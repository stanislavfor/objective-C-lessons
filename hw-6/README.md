# Objective-C для iOS-разработчиков. Обучение в записи
## Урок 12. Семинар: Работа с файлами. Обработка ошибок. Objective-C Runtime. Жизненный цикл UIViewController
<br><br>

1. Создайте мобильное приложение на языке Objective — C, которое бы сохраняло некоторые пользовательские данные в различные хранилища, а именно: <br>
   — UserDefaults <br>
   — KeyChain <br>
   — PropertyList <br>
   — FileManager <br>
   — *YapDataBase <br> <br>

2. Создайте программу, которая экстренно выбрасывает исключение. Необходимо обработать данное поведение так, чтобы не было Crash’a вашего мобильного приложения.  <br><br>

3. Переопределите все методы жизненного цикла ViewController’a и с помощью Objective — C Runtime замените их имплементацию.  <br>
   *Также попробовать заменить имплементацию стандартных методов из Private SDK Apple, например, _handleLongTapEvent, название методов можно посмотреть в дебагере. <br>

<br><br>

### Решение задания

<br><br>

По заданию требовалось создать UI мобильное приложение вместо консольного приложения. <br>
Добавить элементы для первого - начального и вторго экранов. <br>
Записать текстовое поле и для второго экрана реальзовать игру Robot из предыдущей домашней работы. <br>
При необходимости добавить обработку исключений.<br>

<br><br>

#### Описание Мобильного приложения

Мобильное приложение имеет методы сохранения данных в UserDefaults, 
есть функции управления роботом и применена обработка исключений.

**main.m** - точка входа в приложение. <br>
**Info.plist** - файл конфигурации приложения. <br>
**AppDelegate.h, AppDelegate.m** - управление жизненным циклом приложения. <br>
**SceneDelegate.h, SceneDelegate.m** - управление жизненным циклом сцены. <br>
**ViewController.h, ViewController.m** - первый экран приложения для ввода текста, который сохраняется в UserDefaults. <br>
**SecondViewController.h, SecondViewController.m** - второй экран приложения, где есть управление роботом. <br>
**Robot.h, Robot.m** - класс Robot, который представляет робота и методы его функционирования. <br>
**Main.storyboard** - интерфейс, содержащий две страницы (экрана) ViewController. Main.storyboard описывает интерфейс приложения  <br>
с двумя ViewController. Первый ViewController экрана содержит UITextField, UITextView, две кнопки "SAVE" и "FORWARD".  <br>
Второй ViewController экрана содержит два UITextField для ввода координат X и Y, UITextView для отображения координат, две кнопки "START" и "STOP". <br>

<br>

1. После запуска Приложения на первом экране (ViewController) отображается текстовое поле (UITextField), <br>
   текстовое представление (UITextView), две кнопки: "SAVE" и "FORWARD". <br>
2. После ввода текста в текстовое поле (UITextField), например, "Hello, World!", необходимо сохранить текст, <br>
   нажав кнопку "SAVE". Текст "Hello, World!" сохраняется в UserDefaults и отображается в текстовом представлении (UITextView). <br>
3. Нажав кнопку "FORWARD" выполняем переход на второй экран (SecondViewController). <br>
4. На втором экране отображаются два текстовых поля для ввода координат X и Y. <br>
   Вводя начальные координаты для X и Y, например, X = 5 и Y = 10 и нажав кнопку "START", можно включить движение робота. <br>
5. Робот начинает движение, изменяя свои координаты, текущие координаты робота отображаются в текстовом представлении (UITextView). <br>
6. Нажимая кнопку "STOP" можно остановить движение Робота. <br>
7. При закрытии и повторное открытии приложения на первом экране отображается сохраненный текст <br>
   "Hello, World!" в текстовом поле (UITextField) и текстовом представлении (UITextView). <br>
    На втором экране робот продолжает движение с сохраненных координат. <br>
